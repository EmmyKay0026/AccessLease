# AccessLease demonstration artifact

`accesslease-evidence-demo.mp4` is a **174-second narrated evidence walkthrough** (1280×720, H.264 video, AAC audio, about 2.5 MB). It presents the real production responses and Arkiv transaction evidence captured on 18 October 2026. It is explicitly labeled as captured evidence, not a live browser or MetaMask recording.

Use the matching SRT captions and transcript in this directory. A timed live-take script and public-video submission handoff are in [docs/DEMO.md](../../docs/DEMO.md). [docs/SECURITY_EVIDENCE.md](../../docs/SECURITY_EVIDENCE.md) links the raw records and reproduction commands.

Generated with installed Windows SAPI speech, System.Drawing and ffmpeg by `scripts/render-evidence-demo.ps1`. Intermediate frames, WAV files and segments are ignored by Git. No application screen was simulated and no wallet key, nonce or signature appears in the video.
